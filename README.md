# 13 Gypsies — luxury demo (RGWebD design preview)
Static one-page site + Menu page for 13 Gypsies, Spanish tapas in Riverside, Jacksonville FL. Built by RGWebD as a prospect demo.
Rebuild: copy `_generator/` next to an `assets/` folder (fonts, img, favicons) and run `python3 build.py <outdir>`. Facts and sources: `_generator/notes.md`.
